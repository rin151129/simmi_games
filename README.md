# 캔들 차트 마스터 (simmi_games)

캔들 모양을 보고 다음 흐름을 맞히는 주식 공부 퀴즈 게임입니다. 초급·중급·상급 3단계, 패턴 도감, 오답 복습이 들어 있습니다.

- 시작 페이지: `index.html` (게임이 바로 열립니다)
- 단일 HTML 파일이라 인터넷 없이 내려받아 열어도 그대로 실행됩니다. 외부 라이브러리·CDN을 쓰지 않습니다.
- 검색 노출 방지를 위해 `index.html`에 `<meta name="robots" content="noindex, nofollow">`를 넣었습니다.
- 모바일 크롬·사파리 기준으로 만들었습니다.
